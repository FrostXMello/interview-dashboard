# Supabase

Schema and RLS live in `migrations/` (apply in filename order).

Local stack (requires a running Docker daemon):

```bash
supabase start
supabase db reset
```

Live RLS/Auth checks (requires a JWT anon key + service role in the shell):

```bash
npm run verify:rls
```

See [docs/LIVE_VERIFICATION.md](../docs/LIVE_VERIFICATION.md).

`config.toml` was generated by `supabase init` so the CLI can start a local project later. Do not treat init as live verification.
